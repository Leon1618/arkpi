## Australian first aid differs in places

The first-aid pages in this ark come mostly from US sources. In Australia:

- **Choking:** use **back blows and chest thrusts**, not abdominal thrusts. See
  the note in [../01-emergency/choking.md](../01-emergency/choking.md).
- **Burns:** cool under running water for **at least 20 minutes**. See the note
  in [../01-emergency/burns.md](../01-emergency/burns.md).
- **CPR:** the same 30:2 and 100–120 per minute, using the **DRSABCD** steps.
  See the note in [../01-emergency/cpr.md](../01-emergency/cpr.md).
