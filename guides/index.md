# Arkpi — Offline Knowledge Ark

This library works **without internet**. Everything here is stored on this
computer.

!!! danger "In an emergency right now"
    - **Severe bleeding** → [Controlling Severe Bleeding](first-aid/severe-bleeding.md)
    - **No safe water** → [Making Water Safe to Drink](water/purifying-water.md)
    - If phones work, call your local emergency number first (911 in the US, 112 in the EU, 190/192/193 in Brazil).

## Reference library

If the Kiwix server is running, the offline encyclopedia (Wikipedia, WikiMed
medical encyclopedia, and others) is at
[http://localhost:8080](http://localhost:8080).

Start it with `./scripts/serve-kiwix.sh` from the arkpi folder.
